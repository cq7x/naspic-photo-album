# 13 · 照片浏览页（主页）设计与使用

> 版本：v1.1.0 · 前端 `web/src/views/Gallery.vue` · 后端 `server/internal/api/media.go`

主页定位：**打开就是照片墙**——按时间轴浏览、点开即预览，存储管理退居二级页面。

---

## 1. 页面结构

```
┌──────────────────────────────────────────────────────────┐
│ 工具栏  相册▾  [全部][照片][视频][收藏]  日期范围  搜索  │
│         刷新  多选          共 N 项 · X 照片 · Y 视频    │
├──────────────────────────────────────────────────────────┤
│ 批量条（多选时）全选本页  已选 N  收藏  取消  移除索引   │
├──────────────────────────────────────────────────────────┤
│ 今天 周日 · 12 项                                         │
│  ┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐                    │
│  │ ☆  ││ ★  ││    ││ ▶  ││    ││    │   ← 自适应网格     │
│  └────┘└────┘└────┘└────┘└────┘└────┘                    │
│ 2026年9月12日 周六 · 8 项                                 │
│  ...                                                      │
└──────────────────────────────────────────────────────────┘
```

- 日期标题**吸顶**（sticky），长列表滚动时始终知道"看到哪天了"
- 顶部标签优先显示「今天 / 昨天」，更早显示「2026年9月12日 周六」
- 网格 `auto-fill, minmax(150px, 1fr)`，窗口窄自动少列，宽自动多列
- 鼠标悬停显示文件名；右下无角标的是照片，`▶` 是视频

## 2. 缩略图与懒加载

| 档位 | 像素 | 用途 |
|---|---|---|
| `sm` | 256 | 列表网格（可选） |
| `md` | 512 | **网格默认** |
| `lg` | 1080 | 灯箱大图 |
| `sq` | 300 方图 | 预留（人脸/封面） |

- `<img loading="lazy">` + IntersectionObserver 提前 600px 预取下一页
- 缩略图按需生成（懒生成）：第一次访问某张图才调 libvips 生成并落盘缓存，
  后续请求直接命中 `/data/cache/thumbs` 文件
- 加载失败（损坏文件、不支持格式）自动降低透明度占位，**不阻塞**其余图片

### 鉴权：为什么 URL 后面有 `?token=`

`<img src>` / `<video src>` 是浏览器直接发起的请求，带不上 `Authorization` 头。
因此 Auth Middleware 的取 token 顺序为：

1. `Authorization: Bearer <token>`
2. `X-Naspic-Token: <token>`
3. `?token=<token>` ← 仅用于媒体直链

token 存 `localStorage['naspic.token']`，退出登录后自动失效。

## 3. 灯箱预览

点任意图片进入全屏预览：

| 操作 | 快捷键 / 按钮 |
|---|---|
| 上一张 / 下一张 | `←` `→` 或左右箭头按钮 |
| 关闭 | `Esc` 或右上角 ✕ |
| 放大 / 缩小 | `+` `-`，或顶部 ＋ － 按钮（25% ~ 500%） |
| 复位 | `0` |
| 拖动 | 放大后按住鼠标拖动 |
| 收藏 | 顶部 ★（写回数据库 `favorite`） |
| 下载原图 | 顶部「下载原图」，`?download=1` 触发浏览器下载 |
| 信息面板 | 顶部「信息」：文件名、拍摄时间、尺寸、大小、格式、所属库、路径、设备、EXIF、哈希 |

**预加载**：浏览到末尾前 10 张时自动拉取下一页，翻页不会卡在加载中。
**大图回退**：`lg` 缩略图加载失败时自动回退到原图 URL（例如超大图未生成 lg 缓存）。

## 4. 筛选与搜索

| 筛选项 | 参数 | 说明 |
|---|---|---|
| 相册库 | `library_id` | 下拉来自 `/libraries`，清空=全部库 |
| 类型 | `media_type` | 1=照片 2=视频 |
| 收藏 | `favorite` | 1=仅收藏 |
| 日期范围 | `start` / `end` | 支持 `2026-09-01`，`end` 自动补到当天 23:59:59 |
| 关键词 | `keyword` | 对 `filename` 与 `relative_path` 做大小写无关模糊匹配 |
| 排序 | `order=asc` | 默认 `desc`（最新在前） |

统计条实时显示：总项数 / 照片 / 视频 / 收藏 / 占用空间（来源 `GET /media/stats`）。

## 5. 多选与批量

点「多选」进入选择态：

- 点图片即勾选（不再打开灯箱）
- 顶部「全选本页」勾选当前已加载项
- 批量动作：`favorite` / `unfavorite` / `delete`
- 单次上限 2000 条（后端硬限制）

> **移除索引 ≠ 删原图**
> - 挂载库（只读）：只会把 `media_files.deleted_at` 置位，宿主机原图一枚字节都不动；
>   下次全量扫描会重新索引回来，想彻底不出现请把它加入忽略规则。
> - 托管库：默认同样只删索引；`physical=true` 才会删物理文件（Web 端未暴露该开关）。

## 6. 后端接口一览（v1.1.0 新增/变更）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/media` | 列表 + 筛选 + 游标分页，返回 `items/has_more/next_cursor` |
| GET | `/api/v1/media/stats` | 概览统计 |
| GET | `/api/v1/media/:id/detail` | 详情（EXIF / 库名 / 标签） |
| GET | `/api/v1/media/:id/thumb?size=md` | 缩略图（懒生成） |
| GET | `/api/v1/media/:id/file?download=1` | 原图 / 下载 |
| PATCH | `/api/v1/media/:id` | 改收藏、修正拍摄时间 |
| POST | `/api/v1/media/batch` | 批量收藏 / 移除 |
| DELETE | `/api/v1/media/:id` | 删除单个 |

新增字段：`media_files.favorite`（tinyint，0/1，带索引）。
由 GORM AutoMigrate 自动补列，**老库升级无需手工执行 SQL**。

## 6.5 上传照片（v1.2.0）

工具栏「**上传**」→ 选择目标库 → 拖放或点选文件 → 开始上传。

| 规则 | 说明 |
|---|---|
| 目标库 | 只列出**可写**的托管库；挂载目录是只读索引，后端直接 403 拒绝 |
| 归档 | 默认按 `年/月` 子目录归档（如 `2026/09/`），可用 `dir` 参数指定 |
| 重名 | 自动重命名 `xxx (1).jpg`，**绝不覆盖** |
| 重复内容 | 同库相同 SHA-256 命中即秒传（`dedup=true`），不占双份空间 |
| 元数据 | 上传后立即抽 EXIF（拍摄时间 / 设备 / GPS / 方向）写索引，不用等扫描 |
| 文件名 | 清洗 `\ / : * ? " < > |` 与控制字符，防路径穿越 |
| 限制 | 单次最多 200 个文件；扩展名必须在支持列表内 |

前端逐文件上传并显示 `第 n / N` 与百分比，完成后自动刷新时间轴。
没有可写托管库时，对话框会引导去「存储管理 → 新建托管库」。

## 7. 性能取舍

- **游标分页而非 OFFSET**：`WHERE (taken_at, id) < (cursor)`，
  翻到第 1000 页和第一页一样快，依赖 `idx_media_lib_taken(library_id, taken_at)`。
- **一次多取一条**判断 `has_more`，避免额外 COUNT 查询。
- **统计独立接口**且失败静默，不让统计拖慢首屏。
- **ARM / 低配**：缩略图并发按内存档位自动降档（见 `docs/05`），
  首次进相册会看到图片"一张张长出来"，属正常现象；扫描完成后会批量补齐。
