# Naspic 私有云相册 — 移动端自动备份设置页（Uni-app）

> 对应 README 场景10 ｜ 版本：v0.9.0 ｜ 代码：`app/pages/backup/backup.vue`

---

## 1. 页面结构

```
backup.vue（自动备份设置）
├─ ① 总开关：自动备份 开/关
├─ ② 系统相册备份
│     ├─ 启用开关
│     ├─ 上传网络：仅 WiFi / 允许移动网络
│     ├─ 画质    ：原图 / 压缩（长边 1920）
│     └─ 文件类型：照片 / 视频
├─ ③ 自定义文件夹
│     ├─ 添加（SAF 目录选择器 + 持久化授权）
│     └─ 每个文件夹独立配置：
│          启用 / 仅WiFi / 上传原图 / 包含子目录 / 目标相册库
├─ ④ 冲突处理
│     ├─ 保留双方，服务端自动重命名（推荐）
│     ├─ 跳过不上传重名文件
│     └─ 仅按内容去重
├─ ⑤ 同步状态与历史
│     ├─ 立即同步 + 进度条
│     ├─ 失败列表 / 同步日志 / 上次同步时间
└─ ⑥ 后台保活
      ├─ Android：电池优化白名单、自启动、多任务锁定
      └─ iOS：后台 App 刷新、照片权限、充电时同步
```

## 2. 交互逻辑

| 操作 | 行为 |
|---|---|
| 打开总开关 | 展示系统相册与自定义文件夹配置区 |
| 修改任一策略 | ① 写入本地 `store.tasks` ② 调 `PUT /api/v1/sync/tasks` 上报服务端（Web 端可见） |
| 添加文件夹 | 调 SAF `ACTION_OPEN_DOCUMENT_TREE` → `takePersistableUriPermission` 持久化 → 建任务 |
| 移除文件夹 | 删本地任务 + 调 `DELETE /api/v1/sync/tasks/:id`；**手机本地文件不受影响** |
| 立即同步 | 调 `engine.runAll()`，实时进度 + 完成后汇总 Toast |
| 冲突策略 | 存本地设置，上传时随任务上报；服务端永远不覆盖、不删手机原图 |

## 3. 关键代码片段

### 3.1 每个文件夹独立策略

```js
folders.value.push({
  folderUri: picked.uri,     // SAF tree URI
  folderPath: picked.path,
  folderType: 2,             // 1=系统相册 2=自定义文件夹
  enabled: true,
  wifiOnly: true,
  uploadOriginal: true,
  includeSubdir: true,
  fileTypes: ['image', 'video'],
  targetLibraryId: libraries[0].id,   // 只可写入托管库
})
```

### 3.2 配置变更即时上报

```js
async function syncServerTask(t) {
  await api.upsertSyncTask({
    device_id: localDeviceId(),
    folder_uri: t.folderUri,
    folder_type: t.folderType,
    enabled: t.enabled,
    wifi_only: t.wifiOnly,
    upload_original: t.uploadOriginal,
    include_subdir: t.includeSubdir,
    file_types: t.fileTypes,
  })
}
```

### 3.3 目录选择器（Android SAF）

```js
const intent = new Intent(Intent.ACTION_OPEN_DOCUMENT_TREE)
intent.addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)
intent.addFlags(Intent.FLAG_GRANT_PERSISTABLE_URI_PERMISSION)
main.startActivityForResult(intent, 1001)
// 回调中：
main.getContentResolver().takePersistableUriPermission(uri, flags)
// 关键：持久化授权，否则重启 APP 后无法访问该目录
```

### 3.4 后台保活引导

```js
// Android：请求忽略电池优化
const intent = new Intent(Settings.ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS)
intent.setData(Uri.parse('package:' + main.getPackageName()))
main.startActivity(intent)

// iOS：检测后台刷新状态，被关闭时引导去设置页
// 需原生插件读取 UIApplication.shared.backgroundRefreshStatus
```

## 4. 平台差异

| 能力 | Android | iOS |
|---|---|---|
| 目录选择 | SAF `ACTION_OPEN_DOCUMENT_TREE` + 持久化授权 | `UIDocumentPickerViewController` + security-scoped bookmark（需原生插件） |
| 相册枚举 | MediaStore 增量查询（`DATE_MODIFIED > cursor`） | Photos 框架 / PHAsset（需原生插件） |
| 后台执行 | 前台服务 + WorkManager + 电池白名单 | `BGTaskScheduler`（有限时长，充电+WiFi 时调度） |
| 权限 | `READ_MEDIA_IMAGES/VIDEO`（13+）、`READ_EXTERNAL_STORAGE`（≤12） | `NSPhotoLibraryUsageDescription`，支持 limited 模式 |
| 通知 | 常驻通知显示进度 | 本地通知 |

## 5. 数据表映射

页面上的每一项配置最终落到 `sync_tasks`：

| 页面控件 | 字段 |
|---|---|
| 启用开关 | `enabled` |
| 仅 WiFi | `wifi_only` |
| 上传原图 | `upload_original` |
| 包含子目录 | `include_subdir` |
| 文件类型 | `file_types` |
| 目标库 | `target_library_id` |
| 增量游标 | `sync_cursor`（同步成功后自动更新） |

Web 端「存储管理 → 手机设备」可看到同一份配置与进度。
