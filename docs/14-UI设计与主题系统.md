# 14 · UI 设计规范与主题系统

> 对应版本 **v1.3.0**。本文说明前端的视觉体系、文件结构与扩展方式，
> 供后续新增页面时直接复用，避免各处各自为政地写死颜色。

---

## 1. 文件结构

```
web/src/
├─ styles/
│  ├─ theme.css        设计令牌（design tokens）+ 基础重置 + 通用工具类
│  └─ element.css      Element Plus 变量桥接与组件外观覆盖
├─ composables/
│  └─ theme.js         主题状态机（light / dark / auto）与持久化
├─ components/
│  └─ AppIcon.vue      内置线性 SVG 图标（30+ 个，无第三方依赖）
├─ views/
│  ├─ Gallery.vue      照片墙（对齐布局 + 灯箱 + 上传）
│  ├─ Login.vue        登录页（左右分栏）
│  └─ StorageManage.vue
├─ App.vue             应用外壳（侧边栏 + 顶栏）
└─ version.js          版本号单一来源
```

## 2. 设计令牌（`styles/theme.css`）

所有颜色、圆角、阴影都定义在 `:root` 上，深色主题通过 `html.dark` 覆盖同名变量。
**业务代码只消费变量，不写死色值。**

| 类别 | 变量 | 浅色 | 深色 |
|---|---|---|---|
| 品牌 | `--brand` | `#2b5cff` | `#6b93ff` |
| 背景 | `--bg-app` | `#f5f6f8` | `#0e1015` |
| 背景 | `--bg-surface` | `#ffffff` | `#171a21` |
| 背景 | `--bg-subtle` | `#f2f4f7` | `#1d212a` |
| 文字 | `--text` | `#14171f` | `#e9ecf1` |
| 文字 | `--text-sub` | `#5a6272` | `#a2abbb` |
| 文字 | `--text-weak` | `#98a0ad` | `#6f7889` |
| 描边 | `--border` | `#e7e9ee` | `#262b35` |
| 圆角 | `--r-sm/md/lg/xl` | 8 / 12 / 16 / 22px | 同 |
| 阴影 | `--shadow-xs…lg` | 4 级 | 同 |

新增主题色时：在 `:root` 与 `html.dark` 各写一份，组件里用 `var(--xxx)` 引用即可，
不需要为深色写任何额外选择器。

## 3. 主题切换（`composables/theme.js`）

```js
import { useTheme } from './composables/theme'
const { isDark, mode, setMode, toggle } = useTheme()
```

- `mode` 三态：`light` / `dark` / `auto`（`auto` 跟随系统 `prefers-color-scheme`）
- 状态写入 `localStorage['naspic.theme']`
- 切换动作 = 给 `<html>` 增删 `dark` 类 + 同步 `color-scheme`
- Element Plus 的深色变量由 `element-plus/theme-chalk/dark/css-vars.css` 提供，
  同样挂在 `html.dark` 下，因此一次切换同时生效于自绘组件与 EP 组件

## 4. 图标（`components/AppIcon.vue`）

```html
<AppIcon name="star" :size="16" :stroke-width="1.8" />
```

- 24×24 视口、线性（stroke）风格，颜色继承 `currentColor`
- 新增图标：在 `ICONS` 里加一条，`p` = path、`c` = circle `[cx,cy,r]`、`r` = rect `[x,y,w,h,rx]`
- 不引入 `@element-plus/icons-vue`，减少依赖与打包体积

## 5. 照片墙对齐布局算法

`Gallery.vue` 里的 `justify(list, containerWidth, targetHeight, gap)`：

1. 依次把图片放进当前行，累计宽高比之和 `sum`
2. 每加一张就重算行高 `h = (容器宽 - 间距) / sum`
3. 当 `h <= targetHeight` 时该行定稿，按各自宽高比分配宽度
4. 最后一行不足时，行高上限放宽到 `targetHeight * 1.3`，避免单张图撑爆屏幕

容器宽度由 `ResizeObserver` 监听，窗口变化实时重排。
密度三档对应目标行高：紧凑 150 / 标准 210 / 大图 290，选择存 `localStorage['naspic.density']`。

## 6. 应用外壳

- 左侧栏 232px，可折叠到 68px（记忆在 `localStorage['naspic.sidebar']`）
- 导航：照片 `/photos`、收藏 `/favorites`、存储管理 `/storage`
- 侧栏底部：收录统计（总数 / 占用 / 库数量）+ 用户区 + 退出
- 顶栏：页面标题、版本号、主题开关
- 登录页不渲染外壳（`App.vue` 中按 `route.path === '/login'` 分支）

---

## 7. 新增页面的约定

1. 颜色一律用 `var(--xxx)`，禁止硬编码 `#fff` / `#333`
2. 按钮复用 `.btn` / `.btn.primary` / `.btn.ghost` / `.btn.danger`
3. 需要图标就用 `AppIcon`，不要内联 `<svg>`（除非是品牌标识这种一次性图形）
4. 页面根节点加 `np-in` 类获得入场动画
5. 需要占据全高的滚动容器：`height: 100%; overflow-y: auto`

## 8. 常见问题

**Q：加了新组件但深色模式下颜色不对？**
检查是否写了硬编码色值。搜索 `#[0-9a-fA-F]{3,6}` 即可定位。

**Q：Element Plus 组件看起来和自绘组件不一致？**
在 `styles/element.css` 里补变量桥接或选择器覆盖，不要在业务组件里用 `:deep()` 逐个打补丁。

**Q：改了 `--brand` 但按钮没变？**
`element.css` 里 EP 的主色是桥接到 `--brand` 的，引用顺序是
`element-plus/index.css` → `dark/css-vars.css` → `theme.css` → `element.css`，
见 `main.js`，不要调换。
